# 第一章：强化学习与马尔可夫决策过程

## 1. 强化学习的基本要素

强化学习研究智能体（Agent）如何通过与环境（Environment）交互，学习能够获得较高长期回报的行为策略。

一次交互通常包括：

1. 智能体观察当前状态 $S_t$；
2. 根据策略选择动作 $A_t$；
3. 环境转移到下一状态 $S_{t+1}$；
4. 环境返回奖励 $R_{t+1}$；
5. 智能体根据交互结果调整策略。

需要区分几个基本概念：

- **状态（State）**：对当前环境情况的描述，原则上应包含预测未来所需的信息。
- **动作（Action）**：智能体在当前状态下可以采取的行为。
- **状态转移（State Transition）**：环境执行动作后，从当前状态转移到下一状态的过程。
- **奖励（Reward）**：环境对当前交互结果给出的即时反馈。
- **策略（Policy）**：智能体根据状态选择动作的规则，通常写作 \(\pi(a\mid s)\)。

常见的 MDP 五元组写法为：

$$
\mathcal{M}=(\mathcal{S},\mathcal{A},P,R,\gamma)
$$
其中分别表示状态空间、动作空间、状态转移模型、奖励函数和折扣因子。**策略 $\pi$ 是智能体采用的行为规则，通常不是 MDP 五元组中的一个固定组成部分**，而是定义在 MDP 上的决策方案。

## 2. 轨迹、回合与回报

### 2.1 轨迹（Trajectory）

智能体与环境连续交互形成的一系列状态、动作和奖励，称为轨迹。例如：

$$
\tau=(S_0,A_0,R_1,S_1,A_1,R_2,\ldots)
$$
轨迹描述了一次实际发生的交互过程。

### 2.2 回合（Episode）

从初始状态开始，到达到终止状态为止的一段交互过程称为一个回合。存在明确终止条件的任务通常称为回合制任务（episodic task）。

### 2.3 回报（Return）

从时刻 \(t\) 开始，未来奖励的折扣累积和：

$$
G_t=R_{t+1}+\gamma R_{t+2}
+\gamma^2R_{t+3}+\cdots
$$
也可以写成：

$$
G_t=\sum_{k=0}^{\infty}\gamma^kR_{t+k+1}
$$
其中 \(0\leq\gamma<1\) 为折扣因子。回报具有递归形式：

\[
\boxed{G_t=R_{t+1}+\gamma G_{t+1}}
\]

### 2.4 为什么引入折扣因子？

折扣因子主要有两个作用：

1. **使无限长任务的回报具有良好的数学性质。** 当奖励有界且 \(\gamma<1\) 时，无限折扣回报通常可以收敛为有限值。
2. **调节对近期和远期奖励的重视程度。** \(\gamma\) 越小，越重视近期奖励；越接近 1，越重视长期奖励。

折扣因子也会影响智能体对延迟收益的评价。例如，在其他条件相同时，较早获得相同奖励通常比更晚获得更有价值。

### 2.5 回合制任务与持续性任务

- **回合制任务**：任务存在明确的终止状态，例如一局游戏结束或一次搜索任务完成。
- **持续性任务**：任务没有自然终点，交互可以持续进行。

一种常见的数学处理方式是：在回合制任务结束后进入吸收终止状态，之后始终停留在该状态，且后续奖励设为 0。这样可以将有限回合的过程纳入统一的状态转移框架。

## 3. 马尔可夫性质与马尔可夫过程

### 3.1 马尔可夫性质（Markov Property）

如果已知当前状态后，未来状态的分布与更早的历史无关，则满足马尔可夫性质：

\[
P(S_{t+1}\mid S_t,S_{t-1},\ldots,S_0)
=
P(S_{t+1}\mid S_t)
\]

在 MDP 中，考虑动作后可写为：

\[
P(S_{t+1}\mid S_t,A_t,\text{历史})
=
P(S_{t+1}\mid S_t,A_t)
\]

直观理解：**当前状态已经包含预测下一步所需的相关信息，不必再单独追溯完整历史。**

例子：

- **有放回抽牌**：每次抽牌后放回并重新洗牌，下一次抽到什么牌不依赖之前抽到了什么；当前抽牌过程具有马尔可夫性质。
- **布朗运动**：在给定当前时刻的位置后，未来增量的分布不依赖此前的运动历史，体现了马尔可夫性质。

需要注意，马尔可夫性质取决于状态如何定义。如果状态遗漏了影响未来的重要信息，那么观测到的状态可能不满足马尔可夫性质。

### 3.2 马尔可夫过程（Markov Process）

马尔可夫过程通常由状态空间和状态转移规律构成，是描述状态随时间随机演化的模型。

在强化学习中，进一步引入动作、奖励和策略，就形成了马尔可夫决策过程（MDP）。

## 4. MDP：马尔可夫决策过程

MDP 是描述智能体在随机环境中进行序贯决策的数学框架。

其核心组成包括：

- 状态空间 \(\mathcal S\)：所有可能状态的集合；
- 动作空间 \(\mathcal A\)：所有可能动作的集合；
- 状态转移与奖励模型：描述给定状态和动作后，环境可能产生的下一状态及奖励；
- 策略 \(\pi(a\mid s)\)：描述智能体如何根据状态选择动作；
- 折扣因子 \(\gamma\)：描述未来奖励的折扣程度。

常用的联合转移奖励概率为：

\[
p(s',r\mid s,a)
=
P(S_{t+1}=s',R_{t+1}=r\mid S_t=s,A_t=a)
\]

它同时描述下一状态和即时奖励的不确定性。

### 奖励是下一状态的函数吗？

不应一般性地认为奖励只由下一状态决定。更完整的表达是：

\[
R_{t+1}=R(S_t,A_t,S_{t+1})
\]

也可以是随机变量，其分布由当前状态、动作和下一状态共同决定。

在一些特定环境中，奖励确实只与下一状态有关；但这属于特殊情况。

如果只关心给定状态和动作后的**期望即时奖励**，可以定义：

\[
r(s,a)=
\mathbb E[R_{t+1}\mid S_t=s,A_t=a]
\]

因此，教材中常见的 \(r(s,a)\) 通常表示期望奖励，而不一定表示每次交互实际获得的随机奖励。

**注意：** 下一状态的分布由 \(s,a\) 决定，并不意味着实际奖励一定可以仅写成 \(s,a\) 的确定性函数。若奖励还依赖随机的 \(s'\)，应保留 \(s'\) 或使用联合概率模型。

# 第二章：状态价值函数与贝尔曼期望方程

## 1. 状态价值函数

状态价值函数（State-value Function）用于衡量：从某个状态出发，按照给定策略持续行动，未来能够获得多少期望回报。

定义为：

\[
\boxed{
V^\pi(s)=
\mathbb E_\pi[G_t\mid S_t=s]
}
\]

其中：

- \(s\)：当前状态；
- \(\pi\)：后续采取的策略；
- \(G_t\)：从当前时刻开始的折扣累积回报；
- \(\mathbb E_\pi\)：按照策略 \(\pi\) 与环境交互所对应的概率分布取期望。

### 状态价值函数的特点

1. **依赖当前状态 \(s\)**：不同状态对应不同的未来收益。
2. **依赖策略 \(\pi\)**：同一个状态采用不同策略，未来回报可能不同。
3. **在平稳 MDP 和平稳策略下不显式依赖时间 \(t\)**：因为状态转移、奖励规则和策略不随时间变化，所以同一状态的价值不因到达它的时刻不同而改变。

严格来说，价值函数还隐含依赖环境模型和折扣因子。

## 2. 贝尔曼期望方程

贝尔曼期望方程描述状态价值函数的递归关系，是第二章的核心。

### 2.1 从回报递归式推导

由回报定义：

\[
G_t=R_{t+1}+\gamma G_{t+1}
\]

根据状态价值函数定义：

\[
V^\pi(s)=
\mathbb E_\pi[G_t\mid S_t=s]
\]

代入回报递归式：

\[
V^\pi(s)=
\mathbb E_\pi[
R_{t+1}+\gamma G_{t+1}
\mid S_t=s]
\]

利用条件期望与全期望公式，将未来回报按下一状态进行条件化：

\[
\mathbb E_\pi[G_{t+1}\mid S_{t+1}=s']
=V^\pi(s')
\]

因此：

\[
\boxed{
V^\pi(s)=
\mathbb E_\pi[
R_{t+1}+\gamma V^\pi(S_{t+1})
\mid S_t=s]
}
\]

这就是贝尔曼期望方程的期望形式。

**核心理解：当前状态的价值 = 当前一步即时奖励的期望 + 下一状态价值的折扣期望。**

### 2.2 求和形式

在离散状态、动作和奖励空间中，对所有可能的动作、下一状态和奖励求和：

\[
\boxed{
V^\pi(s)=
\sum_a\pi(a\mid s)
\sum_{s',r}p(s',r\mid s,a)
[r+\gamma V^\pi(s')]
}
\]

其中：

\[
p(a,s',r\mid s)
=
\pi(a\mid s)p(s',r\mid s,a)
\]

因此，求和形式与期望形式完全等价：**期望就是按照概率分布对所有可能结果加权求和。**

如果定义期望即时奖励：

\[
r(s,a)=
\sum_{s',r}p(s',r\mid s,a)r
\]

则还可以写为：

\[
V^\pi(s)=
\sum_a\pi(a\mid s)
\left[
r(s,a)+
\gamma\sum_{s'}P(s'\mid s,a)V^\pi(s')
\right]
\]

### 2.3 矩阵形式

对于有限状态空间，将所有状态价值排列为列向量：

\[
V^\pi=
\begin{bmatrix}
V^\pi(s_1)\\
V^\pi(s_2)\\
\vdots\\
V^\pi(s_n)
\end{bmatrix}
\]

定义策略对应的奖励向量：

\[
r^\pi(s)=\sum_a\pi(a\mid s)r(s,a)
\]

定义策略对应的状态转移矩阵：

\[
P^\pi(s,s')=
\sum_a\pi(a\mid s)P(s'\mid s,a)
\]

则贝尔曼期望方程可写为：

\[
\boxed{V^\pi=r^\pi+\gamma P^\pi V^\pi}
\]

矩阵 \(P^\pi\) 的重要性质：

- 每个元素非负；
- 每一行的元素之和为 1；
- 因此 \(P^\pi\) 是行随机矩阵（row-stochastic matrix）。

将未知价值向量移到左侧：

\[
(I-\gamma P^\pi)V^\pi=r^\pi
\]

当 \(0\leq\gamma<1\) 时：

\[
\boxed{
V^\pi=(I-\gamma P^\pi)^{-1}r^\pi
}
\]

这给出了贝尔曼期望方程的解析解形式。

## 3. 状态价值函数的求解

### 3.1 解析解

利用矩阵形式：

\[
V^\pi=(I-\gamma P^\pi)^{-1}r^\pi
\]

可以直接求解线性方程组。

这种方法要求已知环境模型，并且需要处理矩阵求解问题。状态空间较大时，直接求解可能带来较高的计算和存储开销。

### 3.2 数值迭代解

可以先初始化一个价值函数 \(V_0\)，然后反复使用贝尔曼期望方程更新：

\[
\boxed{
V_{k+1}=r^\pi+\gamma P^\pi V_k
}
\]

逐状态写为：

\[
V_{k+1}(s)=
\sum_a\pi(a\mid s)
\sum_{s',r}p(s',r\mid s,a)
[r+\gamma V_k(s')]
\]

通常计算相邻两次迭代的最大误差：

\[
\Delta_k=
\max_s|V_{k+1}(s)-V_k(s)|
\]

当：

\[
\Delta_k<\varepsilon
\]

即可认为数值上收敛并停止迭代。

### 3.3 为什么能够收敛？

定义贝尔曼期望算子：

\[
(\mathcal T^\pi V)(s)=
\mathbb E_\pi[
R_{t+1}+\gamma V(S_{t+1})\mid S_t=s]
\]

迭代过程就是：

\[
V_{k+1}=\mathcal T^\pi V_k
\]

当 \(0\leq\gamma<1\) 时，该算子满足压缩性质：

\[
\|\mathcal T^\pi V_1-\mathcal T^\pi V_2\|_\infty
\leq
\gamma\|V_1-V_2\|_\infty
\]

即经过一次更新，两个价值函数之间的最大差距最多缩小为原来的 \(\gamma\) 倍。

因此，迭代会收敛到唯一的不动点 \(V^\pi\)，即贝尔曼期望方程的解。

### 3.4 自举（Bootstrapping）

数值迭代中，使用当前价值估计 \(V_k\) 计算下一次价值估计 \(V_{k+1}\)，这就是自举。

其核心是：

**利用已有的估计值，更新当前的估计值。**

例如：

\[
V_{k+1}(s)=
\mathbb E_\pi[
R_{t+1}+\gamma V_k(S_{t+1})\mid S_t=s]
\]

这里不需要先获得完整未来轨迹的真实回报，而是使用下一状态当前的价值估计进行更新。

自举是后续 TD（Temporal Difference）方法的重要思想。

## 4. 动作价值函数

状态价值函数评价一个状态；动作价值函数进一步评价在某个状态下执行特定动作的价值。

定义：

\[
\boxed{
Q^\pi(s,a)=
\mathbb E_\pi[G_t\mid S_t=s,A_t=a]
}
\]

即：在状态 \(s\) 下先执行动作 \(a\)，之后按照策略 \(\pi\) 行动，所能获得的期望累积回报。

状态价值与动作价值的关系：

\[
\boxed{
V^\pi(s)=
\sum_a\pi(a\mid s)Q^\pi(s,a)
}
\]

也可以写为：

\[
V^\pi(s)=
\mathbb E_{A\sim\pi(\cdot\mid s)}
[Q^\pi(s,A)]
\]

动作价值函数的贝尔曼期望方程为：

\[
Q^\pi(s,a)=
\sum_{s',r}p(s',r\mid s,a)
\left[
r+\gamma\sum_{a'}\pi(a'\mid s')Q^\pi(s',a')
\right]
\]

# 第三章：最优策略与贝尔曼最优方程

## 1. 为什么需要最优策略？

前两章研究的是：**给定一个策略 \(\pi\)，如何计算它对应的价值函数 \(V^\pi\)。**

但强化学习的最终目标通常不是评价一个已有策略，而是寻找能够获得最大期望回报的策略。

因此，需要引入最优状态价值函数和最优策略。

## 2. 最优状态价值函数与最优策略

### 2.1 最优状态价值函数

在所有可行策略中，某个状态能够达到的最大价值定义为最优状态价值函数：

\[
\boxed{
V^*(s)=\max_\pi V^\pi(s)
}
\]

它表示从状态 \(s\) 出发，在所有策略中能够获得的最大期望累积回报。

### 2.2 最优策略

如果策略 \(\pi^*\) 对所有状态都能达到最优状态价值，则称其为最优策略：

\[
V^{\pi^*}(s)=V^*(s),\quad \forall s
\]

即：

\[
\pi^*\in\arg\max_\pi V^\pi
\]

最优策略可能不唯一。例如，某个状态下有多个动作能够产生相同的最优价值，那么不同的动作选择规则都可能构成最优策略。

## 3. 贝尔曼最优方程

贝尔曼期望方程是在给定策略下对动作求期望；贝尔曼最优方程则是在当前状态下选择能够带来最大期望回报的动作。

### 3.1 展开形式

\[
\boxed{
V^*(s)=
\max_a
\sum_{s',r}p(s',r\mid s,a)
[r+\gamma V^*(s')]
}
\]

若使用期望符号：

\[
V^*(s)=
\max_a
\mathbb E[
R_{t+1}+\gamma V^*(S_{t+1})
\mid S_t=s,A_t=a]
\]

两者的核心区别：

- 贝尔曼期望方程：按照给定策略的动作概率求加权平均；
- 贝尔曼最优方程：在所有可选动作中取最大值。

### 3.2 最优动作价值函数

定义：

\[
Q^*(s,a)=
\max_\pi Q^\pi(s,a)
\]

则：

\[
\boxed{
V^*(s)=\max_a Q^*(s,a)
}
\]

相应的贝尔曼最优方程为：

\[
Q^*(s,a)=
\sum_{s',r}p(s',r\mid s,a)
\left[
r+\gamma\max_{a'}Q^*(s',a')
\right]
\]

### 3.3 关于矩阵形式

给定一个固定策略时，贝尔曼期望方程可以写为线性矩阵方程：

\[
V^\pi=r^\pi+\gamma P^\pi V^\pi
\]

但贝尔曼最优方程包含对动作的最大化运算：

\[
V^*(s)=\max_a
\mathbb E[r+\gamma V^*(S')\mid s,a]
\]

因此它是一个非线性算子方程，通常不能直接写成一个固定矩阵的线性方程。可以使用贝尔曼最优算子来表示。

## 4. 压缩映射与贝尔曼最优方程的求解

### 4.1 贝尔曼最优算子

定义：

\[
(\mathcal T^*V)(s)=
\max_a
\sum_{s',r}p(s',r\mid s,a)
[r+\gamma V(s')]
\]

那么贝尔曼最优方程可以写为：

\[
\boxed{V^*=\mathcal T^*V^*}
\]

即最优价值函数是贝尔曼最优算子的一个不动点。

### 4.2 压缩映射性质

对于任意两个有界价值函数 \(V_1,V_2\)，当 \(0\leq\gamma<1\) 时：

\[
\boxed{
\|\mathcal T^*V_1-\mathcal T^*V_2\|_\infty
\leq
\gamma\|V_1-V_2\|_\infty
}
\]

这说明贝尔曼最优算子是压缩映射。

根据压缩映射不动点定理：

1. 贝尔曼最优方程存在不动点；
2. 该不动点唯一；
3. 从任意有界初始价值函数出发，反复应用贝尔曼最优算子，都会收敛到该不动点。

因此，最优状态价值函数 \(V^*\) 存在且唯一。

## 5. 价值迭代与最优策略求解

### 5.1 价值迭代（Value Iteration）

将贝尔曼最优方程中的 \(V^*\) 替换为当前估计值 \(V_k\)：

\[
\boxed{
V_{k+1}(s)=
\max_a
\sum_{s',r}p(s',r\mid s,a)
[r+\gamma V_k(s')]
}
\]

基本过程：

1. 初始化价值函数 \(V_0(s)\)；
2. 根据贝尔曼最优方程更新所有状态的价值；
3. 计算相邻两次迭代的最大误差；
4. 当误差小于阈值时停止迭代。

与策略评估相比，价值迭代在每次更新时直接对动作取最大值，不需要先固定一个策略并完整评估它。

### 5.2 从最优价值函数得到最优策略

得到 \(V^*\) 后，可以选择使贝尔曼最优方程右侧达到最大值的动作：

\[
\boxed{
\pi^*(s)=
\arg\max_a
\sum_{s',r}p(s',r\mid s,a)
[r+\gamma V^*(s')]
}
\]

这就是贪婪策略（Greedy Policy）。

在有限 MDP、折扣因子小于 1 等常见条件下，至少存在一个确定性的贪婪最优策略。

**最优策略不一定唯一，但总存在一个确定性的贪婪最优策略。**

## 6. 最优策略受哪些因素影响？

最优策略主要取决于：

1. **状态转移模型**：不同动作可能导致不同的下一状态分布。
2. **奖励函数**：决定智能体希望获得什么样的反馈。
3. **折扣因子**：决定智能体对近期和远期奖励的相对重视程度。

因此，改变奖励函数或折扣因子，都可能改变最优策略。

### 6.1 奖励函数的仿射变换

考虑奖励变换：

\[
R'=aR+b
\]

其中 \(a>0\)，\(b\) 为常数。对于每一步都增加同一个常数奖励、且采用无限折扣回报的情形：

\[
\begin{aligned}
G'
&=\sum_{k=0}^{\infty}\gamma^k(aR_{t+k+1}+b)\\
&=aG+\frac{b}{1-\gamma}
\end{aligned}
\]

由于 \(a>0\)，所有策略的价值都经过相同的正比例缩放和常数平移，因此策略之间的优劣顺序不变，最优策略保持不变。

需要注意：这一结论依赖于变换条件。对于有限回合且回合长度不同的任务，额外常数奖励可能使长回合获得更多累计奖励，从而改变最优策略。

### 6.2 折扣因子与无意义绕路

折扣因子会降低延迟奖励的价值。

假设两个策略最终都能获得相同奖励 \(R\)，但一个策略立即获得，另一个策略需要等待 \(n\) 步，则对应回报分别为：

\[
G_1=R
\]

\[
G_2=\gamma^nR
\]

当 \(0<\gamma<1\) 且 \(R>0\) 时：

\[
G_1>G_2
\]

因此，在其他条件相同的情况下，折扣因子会使智能体倾向于更早获得奖励，从而抑制为了等待相同收益而进行的无意义绕路。

但折扣因子并不能保证所有循环行为都被消除。如果循环本身能够持续产生正奖励，那么循环仍可能具有较高价值。实际任务中还需要结合奖励设计、终止条件和约束来处理。

# 四、前三章知识之间的关系

前三章可以串联为一条完整的理论主线：

1. **第一章：建立环境模型。** 使用 MDP 描述状态、动作、状态转移、奖励和策略。
2. **第二章：评价给定策略。** 定义状态价值函数和动作价值函数，通过贝尔曼期望方程计算策略价值。
3. **第三章：寻找最优策略。** 引入最优价值函数，通过贝尔曼最优方程和价值迭代求解最优价值，再提取最优策略。

核心公式汇总：

| 知识点 | 公式 |
|---|---|
| 折扣回报 | \(G_t=R_{t+1}+\gamma G_{t+1}\) |
| 状态价值函数 | \(V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s]\) |
| 贝尔曼期望方程 | \(V^\pi(s)=\mathbb E_\pi[R_{t+1}+\gamma V^\pi(S_{t+1})\mid S_t=s]\) |
| 矩阵形式 | \(V^\pi=r^\pi+\gamma P^\pi V^\pi\) |
| 解析解 | \(V^\pi=(I-\gamma P^\pi)^{-1}r^\pi\) |
| 策略评估迭代 | \(V_{k+1}=r^\pi+\gamma P^\pi V_k\) |
| 动作价值与状态价值 | \(V^\pi(s)=\sum_a\pi(a\mid s)Q^\pi(s,a)\) |
| 最优状态价值 | \(V^*(s)=\max_\pi V^\pi(s)\) |
| 贝尔曼最优方程 | \(V^*(s)=\max_a\mathbb E[R_{t+1}+\gamma V^*(S_{t+1})\mid s,a]\) |
| 价值迭代 | \(V_{k+1}(s)=\max_a\mathbb E[R_{t+1}+\gamma V_k(S_{t+1})\mid s,a]\) |
